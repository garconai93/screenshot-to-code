# Screenshot → Code

AI-powered tool that converts UI screenshots into clean, working HTML/CSS code. Built with Gemini Vision API.

## Features

- **Drag & Drop Upload** — Drop a screenshot or click to browse
- **AI Vision Analysis** — Sends to Gemini AI for intelligent code generation
- **Live Preview** — See your converted UI instantly in an embedded iframe
- **HTML + CSS Tabs** — View and copy code separately
- **Export Options** — Copy to clipboard or download as HTML file
- **Dark Theme** — Modern, glassmorphic UI with violet/cyan accents

## Tech Stack

- Vanilla HTML/CSS/JavaScript (no build step)
- Gemini 2.0 Flash Vision API
- GitHub Pages hosting

## Usage

1. Enter your [Gemini API key](https://aistudio.google.com/app/apikey)
2. Upload a screenshot of any UI
3. Click "Convert to HTML/CSS"
4. Copy or download the generated code
